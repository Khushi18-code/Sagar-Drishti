About Sagar Drishti

Sagar Drishti ("ocean vision") is a 3D ocean data visualization platform built for INCOIS (Indian National Centre for Ocean Information Services). It renders the water column as an interactive cross-section — real Argo float positions and profiles alongside gridded temperature, salinity and chlorophyll fields.

The View A / View B toggle shows what EnOI data assimilation actually does: it corrects the raw ocean model to align with real in-situ buoy readings, measurably cutting RMSE against observations.

Pipeline: INCOIS ERDDAP (Argo + model grids) → Flask backend → 3D viewer → Compare & Analysis.

Role: — · Model vs. observation comparisons and depth/time/variable data are sourced from live backend data when available; if live data retrieval fails due to a server or data-source issue, the interface may display fallback/illustrative data.
