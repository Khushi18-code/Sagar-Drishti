# SAGAR-DRISHTI

SAGAR-DRISHTI is an ocean-data visualization and analysis platform for
exploring ocean model and observation data.

## Features

- 3D ocean visualization
- INCOIS Argo observations
- Copernicus Marine model data
- Model-observation comparison
- Data quality analysis
- Ocean trajectory visualization
- Metadata and data provenance
- JSON/CSV/NetCDF data handling

## Technology

- Python
- Flask
- Xarray
- NumPy
- Pandas
- JavaScript
- HTML/CSS
- Copernicus Marine
- INCOIS Argo

pip install -r requirements.txt
